# 🎵 Soundwave - Spotify Clone UI

A modern, responsive Spotify-inspired music player UI built using pure HTML, CSS, and JavaScript. This project replicates the look and feel of a real-world music streaming platform with smooth animations and interactive controls.

---

## 🚀 Live Demo
🔗 (https://anujshield.github.io/spotify-clone/)

---

## 📌 Features

- 🎧 Spotify-like modern UI design
- 🎵 Interactive music player controls (Play/Pause, Next, Previous)
- 💚 Like/Unlike songs functionality
- 🔀 Shuffle and 🔁 Repeat options
- 📊 Dynamic progress bar & time updates
- 🔊 Volume control slider
- 🎨 Smooth animations and hover effects
- 📱 Fully responsive layout
- 🌙 Dark theme UI

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & Animations
- **JavaScript (Vanilla JS)** – Functionality & Interactivity
